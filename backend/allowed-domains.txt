# Proctor — allowed (whitelisted) domains
# ---------------------------------------------------------------------------
# Activity on these is NOT counted as a violation. Keep this list AS SMALL AS
# POSSIBLE. Students are told not to switch tabs at all during the exam; this
# list exists only so the unavoidable, automatic navigation of taking the exam
# (logging in, the exam form itself, a page that opens by itself) doesn't
# produce false violations. It is NOT a list of "things students may do."
#
# MATCHING
#   - "host"          matches that host and any subdomain, ANY path.
#   - "host/path"     matches only that path (and children). Use this to allow
#                     one part of a shared host without opening the rest —
#                     e.g. "docs.google.com/forms" allows Google Forms but NOT
#                     Google Docs/Sheets/Slides on the same host.
#   - Browser-internal pages (chrome://, about:, chrome-extension://, …) are
#     always allowed in code — don't list them.
#   - The exam's own link (set per exam) is auto-whitelisted, scoped to its path.
#   - Lines starting with # are comments. Edit + restart the backend to apply.
#
# WHY IT'S THIS SHORT (from analysing the live test logs):
#   - "docs.google.com" (whole host) let a student open a saved Google Doc to
#     read answers → scoped to /forms only.
#   - "www.google.com" was 100% /search (looking up answers) → removed.
#   - teams / sharepoint / azure / office / au.edu were students in other
#     services mid-exam, not login → removed. If a future exam legitimately
#     needs one, add it here (path-scoped) or set it as the exam link.
# ---------------------------------------------------------------------------

accounts.google.com          # Google sign-in / the login redirect chain
docs.google.com/forms        # Google Forms ONLY — not Docs, Sheets, or Slides
forms.gle                    # short links that redirect to a Google Form
